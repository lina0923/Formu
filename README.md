# Formulario SENA V1

Este es un formulario web creado con HTML y CSS que recopila datos de usuarios como nombre, correo electrónico, edad, intención de compra de coche, marca favorita y medios de transporte usados. También permite agregar comentarios o sugerencias.

## 📋 Características

- Campos de entrada para:
  - Nombre
  - Correo electrónico
  - Edad
- Selección de intención de compra de coche
- Selección de marca de coche favorita
- Selección múltiple de medios de transporte (checkboxes)
- Campo de comentarios adicionales
- Botón para enviar el formulario

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3 (en archivo externo `style.css`)
